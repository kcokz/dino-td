## 实际（代码和游戏里）

- 烤肉（不用器皿）：**回血 + 建造变快**。没有生命上限，没有走路。
- 石锅煎：**回血 ×1.5 + 生命上限 + 建造变快**。
- 走路变快只来自**皮靴**（×1.2，永久）。人的面板上移动速度条没有金色那一截，吃饱时底下写的是"吃饱：建造 ×1.3"。

设计书 4.5 正文已经是对的（第 170 行："走路快从 v0.6 第三轮起是鞋子的事……饭不再管走路"），但同一节的表和别的章节还是旧的。
