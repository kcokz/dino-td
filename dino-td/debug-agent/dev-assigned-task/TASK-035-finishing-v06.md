2. **BUG-023 复测**：夜里翻电池（不点火 / 举火把 / 关掉植龙），每只醒来的守卫是不是先站起来示威、2 秒以后才扑；示威时人走开，它是不是作罢、过一阵又躺下；举火把时是不是一起醒、一起示威。白天照旧。截图或连拍。
