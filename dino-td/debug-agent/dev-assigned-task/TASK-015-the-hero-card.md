## 要测什么
玩家说面板太大（"surviver面板太大，大部分时间都是要选着这个人到处采到处造，这个面板就一直占着游戏版面……有没有方法既方便建造有不要一直显示着这个面板？"），看过第一版又说"最好建造和吃的两个图标不要变动位置，就在右下角原处（除了按c打开点击左下头像应该也可以打开）"。改成（设计书"人的面板平时不开"）：
- "建造""吃饭"两个图标一直在右下角原处（数字键 1、2），开着什么都不挪、不消失。选着人时平时没有面板；他的血量、正在吃的饭在左下角的头像徽章上。
- 按"建造"（或 1）：建造菜单从两个图标上方弹出，"建造"图标是按下去的样子（字变金色）；菜单里只有能造的东西和一行说明，没有人的头像和横条。菜单开着时 1～6 选建筑，两个图标的键位标记收起。选中一样建筑菜单就收起，建筑还在手里、可以一直放到材料不够；要下一样再按 1。再点一次"建造"也收起。"吃饭"一样，吃了就收起，那一行写"选一顿饭吃"。
- 按 C，或者点左下角的头像徽章（徽章角上标着 C）：打开他的属性卡（头像、三条横条、饭、能力槽、他在做什么），卡上**没有命令**。再按 C、再点徽章、Esc、选别的东西、点空地都会关上。在建造菜单里按 C，直接换成属性卡。
- 选中别的东西（建筑、工位、树），它的卡片也立在两个图标上方。数字键归标着键的一边：被咬过的栅栏"修理"是 1，这时两个图标不标键、1 不是建造；完好的栅栏只有"拆除"，1、2 还是建造、吃饭。选着别的东西时点"建造"，会选中人、打开他的建造菜单。
- Esc 一层层退：手里的建筑 → 菜单 → 属性卡 → 选中的东西 → 游戏菜单。
- 设置页"命令"那一行写了 C；徽章的提示写"点这里或按 C 看他的全部属性"。

### 观感

- **平时的右下角很干净**：只剩两个小方块，看地图不挡了。左下角头像旁边那一行"吃饱：生命上限 +2 · 建造 ×1.3 · 1:30"也很好，不用开卡就知道饭还剩多久。
- **徽章上的 C 太小，不容易发现**：截图里大概 10 像素，灰色，贴在头像右上角。第一次玩的人很可能不知道能点。建议 C 做大一点、亮一点，或者开局第一次选中人时提示一句"按 C 看他的全部属性"。
- **"吃饭"图标上有两个数字**：左上角是键位"2"，右上角是饭的份数"1"，一样大小。第一眼分不清哪个是键、哪个是数量。建议饭数换个样子（比如圆底、金色，或者放在下面）。
- **选好建筑菜单就收起**：连着造几样不同的东西时，每换一样多按一次 1（1 → 选 → 放 → 1 → 选 → 放）。多一下不算麻烦，而且造同一样可以一直放，大部分时候够用。要是想更顺手，可以让 Shift + 数字选中时菜单不收起。
- 小事：Esc 从"只选着人"直接到游戏菜单，中间没有"取消选中"那一层，因为人本来就是默认选中的。这样挺合理，只是和任务里写的五层对不上，提一句。
