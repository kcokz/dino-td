## 改了什么
玩家 2026-09-30："精修恐龙blender形象，每个恐龙都要修，因为这是这个游戏最重要的模型，它们最终要有个图鉴系统"；身体结构和肌肉、皮肤细节、花纹和颜色、动作四样都修。设计书 7.1；VERSION.md v0.6 最后"每种恐龙从头做（精修）"一条。

- 十种都是新做的（`tools/generate_dinos.py`，`assets/models/dinos/<种>.gltf`）：腔骨龙、腔骨龙头领、黄昏鳄、植龙、波斯特鳄、扁肯氏兽（第 1 站），迅猛龙（带羽毛）、迅猛龙头领、霸王龙、翼龙（后面几张图的）。不再借 Quaternius 的骨架和动作。
- 每种有自己的骨架和算出来的动作：四足的（黄昏鳄、植龙、波斯特鳄、扁肯氏兽、翼龙）用四足走法；待机呼吸、转头；扁肯氏兽低头吃草。步幅按游戏里走 1.6、跑 4 米/秒算，脚应该不打滑。
- 皮肤是烘焙的颜色图 + 凹凸图；眼睛是顶点色（之前所有恐龙眼睛都是白的——导出器写了一层全白的顶点色，已修）。
- 波斯特鳄比例改了：腿长、站得高，游戏里约 5.4 米长（原来近 7 米）。
- 翼龙在 `Config.DINOS` 里的高度从 0.5 改成 2.2（它还不在任何地图上）。

## 要测什么
1. **眼睛**：白天近看每种（腔骨龙、头领、黄昏鳄、植龙、波斯特鳄）眼睛是有颜色的虹膜和瞳孔，不是白球。夜里植龙的眼睛反光（火光边上）还正常吗？截图。
2. **走路脚滑不滑**：一波来袭里腔骨龙走、跑时脚是不是踩住地面（不滑冰、不原地踏步太快或太慢）；黄昏鳄跑（一蹿一蹿）；波斯特鳄（最后一波）走。挤在栅栏前、被卡住时是不是站着不动而不是原地走。
3. **倒下**：打死的恐龙按身体宽度侧倒、躺两秒、沉下去——波斯特鳄现在腿长了，倒下时有没有穿进地里或飘在空中？截图。
4. **扁肯氏兽**：谷壁上的兽群吃草（低头、嚼、偶尔抬头）、慢慢走；有没有走进河里、陷进地里或浮在空中。
5. **远看**：默认镜头下，来袭的腔骨龙和头领、黄昏鳄在草地上认不认得出来（颜色比原来深）；夜里呢？
6. **性能**：新模型带贴图（总共 30 MB）。满 30 只的来袭时帧率和原来比有没有明显下降？开局加载时间？（`play:` 长局里记一下）
7. **后面几张图的四种**：目前没有地图用它们，用 playtest 的 `gaits`（`only:raptor` 等）或 `scale` 场景看：迅猛龙的羽毛（折起的前臂上一排飞羽、尾巴后半段一扇尾羽）、第二趾抬起的镰刀爪；头领的红羽冠；霸王龙；翼龙折起的翅膀（翼尖竖在背后）走路时会不会张开乱甩。截图。
8. 全程没有 SCRIPT ERROR；`play:20` 两张图各一局。
