## 改了什么
v0.7 的几批（VERSION.md v0.7 第九～十二批；设计书 2 章"恐龙为什么来撞船舱"、3.0、6.0）：

1. **治疗舱**（daeb3f2）：厨房换成治疗舱，吃饭喝水全拿掉。人受伤后右下角有"休息"，点了他走进舱里泡着回血，满了自己出来；再点一次或给别的命令就叫他出来。他在舱里时别的台子都不干活。随身只剩骨镐、石斧、兽皮地图。
2. **四座塔一套**（edbd1a1）：弩塔、落木塔（原来的滚木塔）、投石塔、诱饵台，同一个底座、一圈范围、不分朝向（不再按 R 转）。落木塔把圈里最近的地面恐龙砸倒并推开（大家伙只有压石落木推得动）；投石塔往圈里最挤的地方扔，脚边（内圈暗的那块）扔不着；诱饵台每只恐龙只吃一次。塔开火前先转向目标。
3. **链鳄和剑龙**（c688588）：第 1 站第 2 天起来袭里有链鳄，第 2 站第 3 天起偶尔有剑龙。都披甲：箭只打进四分之一，落木和投石全进。它们不理人，直奔船舱、撞挡路的东西；进了火光（夜里点着的篝火火盆、火罐烧着的地、火把）就喷鼻子掉头跑出场外，不算杀死。第一次看到时人会说一句。
4. **开场动画**（90b17fe）：在开始界面选了游戏后，镜头往上找到天上着火的船舱，跟着它砸下来，震一下、扬尘、地上一圈尘浪，然后雾里传来叫声，镜头回到平常视角，他从舱里出来，顶上一句提示。点一下或按任意键跳过。重开一局不放，跳到第 2 站是跳站自己的落地。

5. **血量和伤害都乘了 4**（959e523，玩家定："调整幅度太大……乘以4"）：人 40 血、一下 4；船舱 400；腔骨龙 11.2 血。谁挨几下倒下和以前一样，只是数字变大了，不是 bug。只有木箭改了：12→10，现在两箭射死一只腔骨龙（以前一箭）；落木 8→9。

## 要测什么
1. **开场动画**：从开始界面进"我们的游戏"、进一次自定义游戏，各看完一遍、各点一下跳过一遍。截图：火尾、落地扬尘、结束后的画面。看：动画中按空格、Esc、点鼠标会不会打开暂停菜单或下命令（应该只是跳过）；跳过后游戏是否正常开始（时间在走、能下命令）；船舱是否摆正在原地；人在不在门口。"再来一局"后不应该再放。
2. **治疗舱**：让人被咬到半血，点"休息"：他是否走进舱里、浮在液体里、血在涨、满了自己出来；中途点地面让他走，是不是马上出来。舱里有人时点工作台下单，看是否等他出来才做。截图。
3. **四座塔**：四种各造一座，选中看蓝圈（投石塔中间暗圈）。看落木塔砸到恐龙时它是否倒地、被推开；投石塔是否不往脚边扔；诱饵台上肉被吃掉后同一只是否还回来吃。塔开火前转向时有没有抖动或转错方向。截图。
4. **链鳄**：玩到第 2 天来袭，找一只链鳄：箭射它掉血是不是很慢；它是不是不理人直奔船舱或挡路的墙；夜里让它走进篝火的光里，看它是否掉头跑走、跑出场外消失。截图一张它掉头的样子。人第一次看到时说的那句是否出现、每波只说一次。
5. **血量乘 4**：看人的卡片、船舱的血条、塔的卡片上的伤害数字显示正常（没有被截断、没有小数点乱跳）；弓塔打腔骨龙是不是两箭一只。
6. 全程没有 SCRIPT ERROR。
