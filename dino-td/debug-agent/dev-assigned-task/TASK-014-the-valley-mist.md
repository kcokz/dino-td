## 要测什么
玩家觉得全黑不真实（"考虑到这是一个追求真实场景的游戏，全黑是不是有点不真实"），要求"只要玩家能感觉出来这个雾是迷雾不是天气就行"。迷雾改成了雾（设计书 9.3 迷雾那一条）：

### 你问的两个看法

- **会不会被当成天气？** 不会。它只盖在没去过的地方，人周围一直是一块干净的圆，一走雾就退，开局还有一句提示，玩家很快会明白这是"没去过"。但它**不太像雾**，更像一张**平的、发白的纸或者雪地**：几乎不透（0.9），上面只有很淡的纹理和几道斜的直线（像拉伸过的贴图），看不出高低、看不出在"飘"。静止截图里我看不出它在动。
- **正午会不会太白、太亮？** **会。** 开局默认视角下 80% 左右的画面是一片接近白色的灰，比地面、比船舱都亮，眼睛先看到的是雾，不是基地。建议：正午的雾色再压暗、偏一点绿灰或者带一点地面颜色；或者让 `never` 不要那么不透，能隐约看到地面起伏（你写的"只隐约透出地面起伏"，截图里基本看不出来）。

### 另一条观感（不是这次问的，但值得看）

- **黄昏和夜里，雾比看得见的地方还亮。** 黄昏：雾是鲜亮的橙粉色，人周围看得见的那块反而是深褐色；夜里：雾是深蓝，看得见的那块几乎全黑。结果是"没去过的地方"比"自己的地方"更显眼，和白天正好相反。玩家的视线会被雾吸过去。建议黄昏和夜里的雾色比看得见的地方暗一档。
