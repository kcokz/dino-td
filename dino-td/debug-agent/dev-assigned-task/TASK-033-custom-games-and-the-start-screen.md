## 要测什么（要用正常启动的游戏，不是工具搭的关卡——工具搭的关卡没有开始界面）
1. **开始界面**：启动后先出来；"开始游戏"直接开始（不重新读关卡），和以前一样修信标；"游戏设置"打开设置页，返回回到开始界面；ESC 菜单"新的一局"回到开始界面，这时游戏是停住的。截图。
2. **自定义页**：每一项的下拉和说明；窗口 1280×720 时能滚到底、看得到"开始"；中英文都看一遍（字有没有缺、有没有挤出框）。选好开始以后再回来，上次的选择还在。截图。
3. **难度和巢**：困难、噩梦在小山谷和大山谷各开一局：几个巢、每个巢的守卫、来袭是不是每个巢都出来一路、黄昏回不回各自最近的巢、预警有没有说出每个巢的方向；巢之间、巢和船舱之间有没有路被堵死；巢有没有压在树、石头、残骸上。截图。
4. **晚白垩世**：迅猛龙来袭（白天夜里都来）、第 3 天起翼龙跟着来、首领迅猛龙头领、大波、最后一天霸王龙；守卫是迅猛龙；没有兽群、河里夜里不上东西。有没有 SCRIPT ERROR、有没有没声音的（它们借了三叠纪动物的声音）。
5. **救援**：撑过 3 天的一局打到底（可以加速）：卡片的天数每过一天少一天、最后一天那句变"天一亮救援就到"、第 4 天一早赢、结果画面"获救"。
6. **别的开关**：没有夜晚（黄昏直接跳到第二天早上：灯光会不会一下跳变得很难看？）、没有迷雾、一天长/短（右上角昼夜表的剩余时间对不对）、资源多/少、船舱脆/坚固、开局物资多。
7. **种子**：填同一个种子开两局，第一波的时间和数量一样；空着两局不一样。
8. 全程没有 SCRIPT ERROR；`play:20` 两张图各一局（正式游戏不应该有任何变化）。
