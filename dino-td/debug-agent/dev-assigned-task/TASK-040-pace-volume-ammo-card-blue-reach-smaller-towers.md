## 改了什么
玩家 2026-10-03 的几条反馈，都已经做了（VERSION.md v0.7 第三～六批；设计书 9.3"节奏调整"、7"音量自己调"、6.0 塔）：

1. **节奏**（7dc0440；玩家的儿子 8 岁玩后："又难又简单——简单的是恐龙强度不高，不会给什么真正的压力；难的是造东西要很久"）：造东西快一倍左右（弩塔约 10 秒），徒手采集快三分之一，第一波 3 只（原来 2 只），两波之间 60～90 秒（原来 80～120）。
2. **音量**（f779326；"设置里加一个audio，可以调整音量"）：设置页有"声音"一栏——总音量、音效、环境声三个滑条，0 是静音，下次打开还记得。
3. **弹药卡片**（84906dc；"弹夹的界面需要更清晰和简洁……改成图片，小方块，类似人的能力"）：塔卡片上一个弹夹格（装的什么、条、12 / 20），下面一排小方块（每种弹药一块，右下角库存数，选中的亮框），最右是装填方块（人在路上时亮，装不了时暗，悬停说为什么）。
4. **蓝色范围**（84906dc；"能攻击的范围应该显示蓝色而不是绿色"）：放塔时滚道、落点、射程圈都是蓝的；选中一座塔时也显示（弩塔、诱饵台的圈，滚木塔的滚道，投石塔的落点）。
5. **塔变小**（398ebf0；"log tower太大了……看着不像能一下造好的样子"；"bow tower也显得太大"）：弩塔 1×1（细高瞭望台），滚木塔 2×2，高度不变，滚道 2.4 米宽。

## 要测什么
1. **节奏**：开一局我们的游戏玩到第 10 分钟左右：每座塔造多久（记几座的秒数）、第一波几只、两波之间隔多久。只记数和 bug，不评平衡。
2. **音量**：设置页三个滑条各拖到 0、50、100，听得出变化吗（总音量管全部；音效管砍树、打斗、恐龙叫、点按钮；环境声管山谷的风声虫声、篝火噼啪）；拖到 0 是不是全静。退出重开，滑条还在原处、声音也是。开始界面进设置也一样。截图一张设置页（中英文各一）。
3. **弹药卡片**：选一座空弩塔、装了一半的、满的、库存里没有箭的，各截一张卡片；点另一种弹药的方块（换弹药、人过去装）；点装填方块；按数字键 1/2/3 也能点；悬停每个方块看提示。滚木塔、投石塔、诱饵台的卡片也各一张。看有没有字被截断、方块挤在一起、数字看不清。
4. **蓝色范围**：放四种塔时，地上的范围是不是蓝的（能放、不能放时都是），按 R 转向时滚道跟着转；造好后点选每座塔，地上显示的范围对不对、取消选择后消失。截图。
5. **塔变小**：弩塔、滚木塔和墙、栅栏、别的塔挨着摆，看有没有穿模（滚木塔的原木两头各伸出 0.2 米，挨着门柱、弩塔腿时可能碰到——拍下来）；滚木塔前面隔两格放一段墙，看原木是不是滚到墙就停；恐龙走进滚道时原木是从坡上滚下来的吗。
6. 全程没有 SCRIPT ERROR。
