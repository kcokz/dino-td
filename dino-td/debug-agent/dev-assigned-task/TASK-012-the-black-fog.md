# TASK-012 迷雾：没去过的全黑，远景也遮住
- 状态: done
- 提交: 7817a1e

## 要测什么
玩家："迷雾没有遮挡远景只遮挡了近景很奇怪，而且没去过的地方应该完全看不到而不是地形都知道吧"。迷雾改了画法（`assets/shaders/fog_of_war.gdshader`，整个画面最后盖一层，按每个像素底下的地面去没去过来定多黑）：
- 没去过的：全黑。地形、树、河、石头都看不见；场地外的谷壁、远处、天空也算没去过，全黑。
- 去过但现在看不见的：压暗（`FOG.seen` 0.55），看得见地形和建筑，不画恐龙和守卫。
- 看得见的：原样。
- 拍模型特写（`playtest` 的 portrait）时这一层不画。

## 怎么算过
- 开局截图：只有船舱周围一圈亮，其余全黑，远处的谷壁、树、兽群、河都看不见（原来远景是亮的）。
- 人走一段再回来：走过的地方是暗的地形（看得见），没去过的全黑；两者之间的边是软的，不是一格一格的方块。
- 河：没去过的河段看不见，去过的河段压暗；河在看得见的地方和原来一样（没有被这一层画坏，比如变成河底的颜色）。
- 夜里、黄昏（`day` 场景）：规则一样，看得见的范围小一些。
- 拉远镜头、转到场地边上：场地外一律黑，不会露出谷壁。
- 开销：`play:N` 一局帧率和改之前（e8c10f1 或 7c86862）比没有明显下降（全屏多一层，每个像素读一次深度和一次迷雾贴图）。
- 界面（HUD、面板、提示）不受影响，不会被压暗。

## 结果（debug-agent, 2026-09-28，在 7817a1e 的干净快照上测）

**小观察（不算 bug）：**
- 亮圈边上的树冠会伸到黑的地方，树冠照样画着，黑底上浮着几棵深色的树（每个像素看的是它自己下面的地，树冠下面是看得见的地）。看起来还行，提一下。
- 开局六成多的画面是黑的，是这个做法本身的观感，玩家定。
