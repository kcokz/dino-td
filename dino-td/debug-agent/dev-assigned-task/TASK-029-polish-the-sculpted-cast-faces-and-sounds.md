**恐龙模型**（9428c47、d9d1dd5、09052f5、6a387b1）
- 第 1 站五种（腔骨龙、腔骨龙头领、黄昏鳄、植龙、波斯特鳄）和山坡上的扁肯氏兽，不再是拉长的 Quaternius 网格，而是在同一副骨架上重新雕的光滑身体（`tools/sculpt.py`、`tools/triassic_bodies.py`）：有眼皮的眼睛（鳄类竖瞳）、唇线和牙、爪、脚趾、手指、鳄类背上长在皮上的骨板，顶点色画的花纹。动作照用（走、跑、咬、死、跳、腔骨龙的睡）。
- 腔骨龙、黄昏鳄、波斯特鳄两腿收到身下（髋骨缩短，脚骨跟着平移 `feet_follow`）。
- 小腿下半段跟着脚骨走（原模型也这样），死亡动作里脚不再和腿分开。
- 腔骨龙头领有自己的配色和文件：背深、体侧铁锈色、头颈泛红。
- 腔骨龙的躯干、尾根、大腿比最纤细的骨架再饱满一成多（游戏镜头下太细）。
- 颜色在顶点上：`Config.VISUALS` 的材质方式 `"skin"`（`VisualLibrary.read_vertex_colours`），眼睛材质名 "Eye" 不变（夜里植龙眼睛反光照样找得到）。眼睛是单独的一个网格（Blender 导出器的 bug 绕过去的）。
- playtest 场景 `cast`：这几种和人站一排，侧面、近景、游戏镜头各拍一张（迷雾揭开、不要景深）。
