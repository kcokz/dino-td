# BUG-026 篝火人能走过去，恐龙还是绕着走

- 状态: fixed（b631095 复测：腔骨龙从篝火中心 0.01 m 走过去，火盆照旧绕 1.35 m）
- 严重度: 低
- 发现: 2026-09-29 · 22743e4 / 2fff793（TASK-027 第 7 条）
- 复现: `GODOT_PROJECT=$(bash debug-agent/tools/snapshot.sh 2fff793) bash debug-agent/tools/run_check.sh probe:round5`（第 7 条那两行）

## 现象

篝火和火盆各放一个，从它们左边 4 米往右边 4 米正中间穿过去：

| | 人离中心最近 | 腔骨龙离中心最近 |
|---|---|---|
| 篝火 | **0.00 m**（踩着过去）✔ | **1.20 m**（绕开了） |
| 火盆 | 0.91 m（被挡，绕开）✔ | 1.41 m |

腔骨龙的路点就是正对着穿过篝火中心（`set_waypoints([篝火右边 4 米, 再右 4 米])`），它还是绕了一米多。

## 猜的原因（没改代码）

人的走法按碰撞体（篝火的碰撞去掉了），恐龙走的是导航网格：篝火大概还在烘导航网格时被挖掉了（和火盆一样），所以恐龙的路绕开它。

## 期望

设计书写"人和恐龙从篝火上走过去"：篝火不挖恐龙的导航网格。（如果只想让人过、不让恐龙过，那设计书那句要改。）
