# BUG-020 能力槽里斧头写"木材 x2"，用的是字母 x，别的都是"×"

- 状态: fixed（0974047 复测："木材 ×2"）
- 严重度: 很低（文字上的一致）
- 发现: 2026-09-29 · 7f8ee65（`probe:kit_slots`，中英文各一遍）

## 现象

人的面板上那排五格，鼠标停上去：

| 格 | 英文 | 中文 |
|---|---|---|
| 斧 | Stone Axe — Wood **x**2 | 石斧 —— 木材 **x**2 |
| 武器 | Bone Spear — hits **×**2 | 骨尖矛 —— 伤害 **×**2 |
| 鞋 | Hide Boots — walks **×**1.2 | 皮靴 —— 走路 **×**1.2 |
| 护甲 | Bone Armour — +5 max health | 骨片甲 —— 生命上限 +5 |

采集加速那一条（镐、斧）是字母 x，别的是乘号 ×。工作台菜单里同一句话也是这个样子（同一个函数）。

## 原因（读代码，没改）

`Config.recipe_effect_text`（Config.gd 507 行）里写死了 `"%s x%s"`，别的几条走的是翻译表里的 `EFFECT_*`（用 ×）。

## 期望

改成 ×，或者也放进翻译表（比如 `EFFECT_HARVEST_SPEED`，"%s ×%s"）。

另外，空格子的提示（"镐 —— 有了才能采石，在工作台做"等五条）都在、中英文都对，这一项（3 章"能力槽悬停文字、空格子的提示"）通过。
