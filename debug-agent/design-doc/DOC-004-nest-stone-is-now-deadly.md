- **探针**（满血、有骨镐，从船舱出发去采，各两次）：

## 为什么写在这里而不是 bug

守卫一起上是有意改的，守卫咬人也没错，所以这不是程序 bug。但它把第 576 行的"打一架"变成了"开局去采东边那块石头大概率会死"，和"人不容易死"对不上。机器人本来就是按"离得最近的石头"去采的，真人第一次玩也很可能这么走。平衡是你和玩家定的，我只把现象和数字放在这里。

## 可选的方向（供参考）

1. 设计书改成实话：第 576 行写明"巢边的石头有三只守卫一起守，开局去采几乎一定会死；开局的石头请去船舱另一侧那块"，并在游戏里给个提示。
2. 或者改摆法：东边那块再挪远一点（离岗位 7.8 米，在"溜达 3 米 + 警戒 6 米"的范围里）。
3. 或者守卫叫同伴时有个前摇（叫一声、隔一两秒同伴才来），给人跑的时间；跑出警戒绳（12 米）它们就回去。
