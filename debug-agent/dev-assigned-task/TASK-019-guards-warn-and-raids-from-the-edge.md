## 改了什么
玩家对 DOC-004 选了 A（守卫先示威再动手），对"巢的实体、来袭从哪来"说："我认为巢穴不应该出来太多，如果需要很多恐龙，比如信标恐龙就应该来自边界，这样即使恐龙走一会儿到也符合一大波的效果，而且从边界出来的你可以先加速后正常速度"。
1. **守卫先示威**（设计书第 3 章"守卫恐龙"）：人走进警戒圈，第一只站住、面朝他、冲空中咬一下、叫一声，同巢的守卫也转过来；2 秒内退到警戒圈外再多 1 米就放过他；靠近任何一只到 3 米以内、打了其中一只、或者 2 秒到了还在圈里，就一起扑上来。每局第一次示威时屏幕上说一句。巢边的建筑照旧直接咬。
2. **巢里只出一小群**（第 3 章"来袭是巢里的一小群猎手"）：每次来袭（普通、信标小波、最后一波）从巢里出来的最多 5 只（`RAIDS.nest_most`），其余从边缘进来：普通来袭和小波从巢背后的边缘（`reinforce_from`），最后一波再加上东、西、南的入口，轮流。
3. **边缘来的先赶路**：没人看见（人、船舱、造好的建筑都看不见那里）、而且离船舱 20 米以外时两倍速度；被看见或者走近了就恢复正常速度，以后不再赶。小山谷的边缘离船舱只有约 21 米，基本不赶；大山谷的在 41 米外。
4. **谁都不在看得见的地方冒出来**：巢正被看着，巢里那一小群改从巢后的边缘进来；边缘的出口有人看着，就换一个没人看着的。
5. **顺带修的**：放下目标、重新上路的来袭会走回出发点（边缘来的走回边缘，巢里的走回巢）。现在接回离它最近的那一段路，朝前走。
