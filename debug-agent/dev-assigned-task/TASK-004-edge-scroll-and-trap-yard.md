## 结果（debug-agent, 2026-09-28，在 ea36313 的干净快照上测）

### 1. 鼠标碰边缘平移：逻辑对；真鼠标那一半没法自动测，请人手测一下

新探针 `probe:edge_pan`，用 `warp_mouse` 把真的光标挪到各处，每处停 1 秒，看镜头焦点动了多少：

- **直接跑：边缘完全不平移（0.00 米）。** 原因是 `Main._mouse_in_window` 一直是 false：`warp_mouse` 挪光标，Windows 不会发"鼠标进入窗口"（根窗口的 `mouse_entered` 收到 0 次）。所以这个结果**不能**说明玩家那边坏了。
- **把 `_mouse_in_window` 强制设成 true 再跑（`DA_FORCE_IN=1`）：**
  - 左边缘 16.1 米/秒，按住 A 是 17.8 米/秒（0.91 倍）；右边缘 18.0 米/秒，方向相反；左上角是斜着走的。
  - 正中间、顶上按钮那一排（y = 30）、离左边 7 像素：都不动。
  - 设置页镜头说明里写着 "WASD or screen edge move"（中文："鼠标移到屏幕边缘平移"）。
- **需要人手测的一种情况**：游戏开起来的时候光标**已经在窗口里**、一直没有出去过，这时候碰边缘会不会平移？`_mouse_in_window` 初始是 false，只有收到 `NOTIFICATION_WM_MOUSE_ENTER` 才变 true。如果开窗时系统不补发这个"进入"，那就要先把光标移出窗口再移回来，边缘平移才开始工作。我这边没法用真鼠标证实，请 dev 或玩家试一下；真是这样的话，就是一个 bug。
- 没测：窗口不在前台时不动（探针的窗口一直在前台）。
