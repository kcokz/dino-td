# TASK-015 人的面板平时只剩两个命令
- 状态: open
- 提交: （提交后填）

## 要测什么
玩家说面板太大（"surviver面板太大，大部分时间都是要选着这个人到处采到处造，这个面板就一直占着游戏版面……有没有方法既方便建造有不要一直显示着这个面板？"）。改成（设计书"人的面板平时只剩两个命令"）：
- 选着人时，右下角平时只有"建造""吃饭"两个图标（数字键 1、2），不带框，只有它们自己那么宽。他的血量、正在吃的饭在左下角的头像徽章上。
- 按"建造"（或 1）：建造菜单从右下角往上长出来，只有能造的东西和一行说明，没有人的头像和横条；选中一样建筑（点或数字键）菜单就收起，建筑还在手里、可以一直放到材料不够；要下一样再按 1。"吃饭"一样，吃了就收起，那一行写"选一顿饭吃"。
- 按 C，或者点左下角的头像徽章（徽章角上标着 C）：打开他的整张卡（头像、三条横条、饭、能力槽、命令），就是原来一直开着的那张。再按 C、再点徽章、Esc、选别的东西、点空地都会关上。在建造菜单里按 C，直接换成整张卡。
- Esc 一层层退：手里的建筑 → 菜单 → 他的整张卡 → 选中的东西 → 游戏菜单。
- 选中别的东西（建筑、工位、树）时，右下角照旧是它完整的卡片。
- 设置页"命令"那一行写了 C；徽章的提示写"点这里或按 C 看他的全部属性"。

## 怎么算过
- 截图（中英文各一套）：选着人的平时样子、建造菜单、建筑拿在手里、他的整张卡、选中一段栅栏。`tools/playtest.gd herocard` 会拍这五张，也可以自己拍。
- 平时样子右下角只剩两个图标，不挡别的界面；菜单、整张卡贴着右下角往上长，不出屏幕、文字不溢出（中文尤其看整张卡和建造菜单的说明行）。
- 键：1、2、C、Esc 按上面的顺序都对；有东西选中时 1、2 按的是那张卡的命令，不是建造、吃饭。
- 机器人整局（`play:N`）不受影响：它照样能造、能吃。
- 请写一两句观感：平时样子够不够小、找不找得到整张卡（徽章上的 C 看不看得见）、选好建筑菜单就收起会不会不方便（要连着造几样不同的东西时）。
