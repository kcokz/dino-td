# TASK-020 迷雾的亮度跟着时辰（TASK-014 的观感）
- 状态: done（正午、白斑、闪烁、帧率过；夜里浓雾纯黑 → BUG-016）
- 提交: 04b79b1

## 改了什么
你在 TASK-014 写的观感："正午会不会太白？会。……80% 左右的画面是一片接近白色的灰，比地面、比船舱都亮"；"黄昏和夜里，雾比看得见的地方还亮……玩家的视线会被雾吸过去"。
- 原来雾是一个颜色，和地面被照得多亮无关。现在雾的**颜色**只取这个时辰环境雾色的色调，**亮度**取它底下那块地面被照得多亮（迷雾那一层读引擎的屏幕纹理，往下取几级 mipmap 只看地面的大起伏），再带三成地面自己的颜色。
- 雾底下的浅色石头原来会变成雾里一团白斑：现在局部亮度不超过周围一大片的亮度。
- 乘上这个时辰的系数（`Config.DAY.light` 每一帧的 `mist`）：白天 1.3（比地面淡一点），黄昏 0.6、夜里 0.5（比看得见的地方暗一档）。
- 以后火照亮的地面，旁边的雾也跟着亮（火还没做，下一个任务）。

## 要测什么
1. 正午、黄昏、夜里各拍一张（开局默认镜头；再走一圈回来，让画面里有"去过"的薄雾）：
   - 正午：雾还白不白？眼睛先看到基地还是雾？
   - 黄昏、夜里：雾是不是比人周围看得见的地方暗？看得见的那一圈分不分得清？
2. 雾里还有没有白斑、亮块、一道道的线（你上次说的"几道斜的直线"）。
3. 还像不像迷雾（不是天气、不是阴影）：没去过的浓雾、去过的薄雾、看得见的，三层分得清吗？
4. 镜头拉远、转视角、抬到看得见天边：天空和谷壁那边的雾有没有怪的地方（发亮、发黑、闪）。
5. 帧率：和 04b79b1 之前比有没有掉（雾那一层现在多读了屏幕纹理）。

## 怎么算过
- 1、3：正午不再发白、黄昏和夜里雾比看得见的地方暗，三层分得清。
- 2、4：没有白斑、闪烁、怪的亮边。
- 5：帧率不明显掉。
- 请写一两句观感：现在的雾像不像山谷里的雾；夜里是不是太黑、看不清自己的基地。

## 结果（debug-agent, 2026-09-29，在 04b79b1 的干净快照上测；对照改之前 d9b75e9）

新探针 `probe:mist_hours`：人先绕一圈（西、南、东）再回来，开局镜头，正午/黄昏/夜里各拍一张并量亮度。画面上场地里的每个采样点投到地面，按迷雾分三层（看得见 / 去过的薄雾 / 没去过的浓雾，只算周围 1.5 m 同一层的点，不算软边）。再把雾揭开量同一批像素，得出雾实际乘了多少。

| | 改之前 d9b75e9 | 04b79b1 |
|---|---|---|
| 正午：浓雾 / 看得见 | 2.38（发白） | **1.03** ✔ |
| 正午：薄雾 / 看得见 | 1.83 | 0.94 |
| 黄昏：浓雾 / 看得见 | 2.76（比看得见的亮） | **0.23** ✔ |
| 黄昏：薄雾 / 看得见 | 1.79 | 0.43 ✔ |
| 夜里：浓雾亮度 | 0.066 | **0.001（纯黑）** ✘ |
| 夜里：薄雾亮度 | 0.044 | 0.014 |

雾实际乘的系数（有雾 ÷ 揭开）：正午 薄 ×1.08 / 浓 ×1.16（设定 1.3）；黄昏 薄 ×0.76 / 浓 ×0.40（设定 0.6）；夜里 薄 ×0.54 / **浓 ×0.05**（设定 0.5）。

1. **正午**：过。雾是灰绿色、半透明，底下的树看得出影子，眼睛先看到基地。**黄昏**：过，雾比看得见的地方暗一档，看得见的一圈分得清。**夜里**：看得见的一圈分得清，但外面没去过的浓雾是一片纯黑 → [BUG-016](../bug/BUG-016-night-thick-mist-is-black.md)。
2. **白斑、亮块、斜线**：过。场地里没有白斑（探针说的几个"亮点"是薄雾里的浅色地面，0.43 对中位数 0.25，看图不显眼）；上次那几道斜的直线没了，现在看到的斜线是雾里的棕榈树干。
3. **三层分不分得清**：正午和黄昏分得清（黄昏浓 0.025、薄 0.046、看得见 0.107）。夜里薄雾 0.014、浓雾 0.001，两个都是黑的，眼睛分不出。
4. **拉远、压低到天边**（tilt 15°、距离 45 m，正午和夜里）：没有发亮、发黑的边，连拍三帧变化 < 0.0001，不闪。
5. **帧率**（1280×720，关 vsync，各跑两次）：空闲 82 / 82 fps，改之前 84 / 83。只掉 1～2 帧，不明显。来袭时的数字两边都乱跳（38～84），是机器噪声，不能比。

**观感**：白天现在像山谷里的雾了：不抢眼，远处的树隐约看得见，比之前那片白好得多。黄昏的暗红雾也对味。夜里基地本身看得清（船舱、人、周围几米都在），不算太黑。但外面的一片纯黑让夜里又像"地图没开"，不像雾。夜里浓雾如果按设定的 0.5 倍走（大约 0.015，和现在的薄雾一样暗），应该就对了。
