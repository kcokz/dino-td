# TASK-024 右下角的命令按解锁先后排
- 状态: done（1～8 都过；观感：新按钮出现不显眼，灰得太淡）
- 提交: 592bac4

## 改了什么
玩家（v0.6 第四轮）："Build 按钮放最右边，哪个能力先解锁放哪个在靠右，以此类推，吃一开始隐藏因为没有食物，火把也是"。
- 开局右下角只有"建造"，在最右边，数字键 1。
- 别的命令第一次能用时才出现，出现在已有按钮的**左边**，拿**下一个**数字键：第一次有做好的饭时出现"吃饭"，第一个黄昏出现"火把"。先到黄昏：火把 2、吃饭 3；先做好饭：吃饭 2、火把 3。
- 出现以后一直在，用不了时是灰的（没饭、正在吃、白天、没木头、火把正烧着）。原来火把按钮白天会收起来，现在不收。已有的按钮永远不挪位置、不换键。
- 第一个黄昏的提示"……点一支火把（N）"、火把烧完的提示，N 是火把按钮自己的键（原来写死 3）。
- 新开一局回到只有"建造"。换语言不算新开一局：按钮和键不变，一局只说一次的话（第一个黄昏、今晚没木头、守卫示威）也不会再说一遍（原来换语言会重置这些）。

## 要测什么
1. 开局（大山谷、小山谷各一次）：右下角只有"建造"，标着 1，按 1 打开建造菜单。
2. **先黄昏后做饭**：不做饭一直到黄昏。火把按钮出现在建造左边、标 2；黄昏的提示写的是 2；按 2 点火把。然后做一顿饭：吃饭出现在火把左边、标 3，按 3 打开吃饭。
3. **先做饭后黄昏**：第一天白天就造厨房做一顿饭。吃饭出现、标 2；到黄昏火把出现在吃饭左边、标 3，提示写 3。
4. 出现以后：天亮时火把按钮还在、是灰的，按它的键没反应；饭吃完吃饭按钮还在、是灰的、角标 0。整局里"建造"按钮的屏幕位置一个像素都不动（其他已有的按钮也不动）。
5. 数字键归谁：打开建造菜单、选中一段被咬过的栅栏（卡片上"修理"是 1）时，右下角按钮的键位标记收起来，关上以后回来，数字没变。
6. 局中在设置页换语言（换过去再换回来）：按钮和键不变；下一个黄昏不再说第一个黄昏的话。**注意不要留下改过的设置**（测完换回原来的语言）。
7. 新开一局（输了以后的"再来一局"、菜单里的重新开始）：回到只有"建造"。
8. 机器人长局：没有 HeroCommands 相关的 SCRIPT ERROR。

## 怎么算过
- 2、3 两种顺序的位置和键都对；4 里没有任何已有按钮挪动；6、7 按上面说的。
- 请写一两句观感：新按钮出现时注意得到吗（现在没有任何提示动画，只是多出来一个）；灰着的按钮会不会让人以为坏了。

**观感：**
- **新按钮出现时注意得到吗**：不太注意得到。它就是多出来一个，那一刻屏幕上多半还有黄昏的提示或者"做好了饭"的提示在说话，眼睛在那边。火把那次好一点，因为黄昏的提示里写了"（2）"，会去找 2。吃饭那次什么都没说。建议出现时按钮闪一下，或者从右边滑进来。
- **灰着的会不会以为坏了**：不会以为坏了，但**灰得太淡**：截图里没饭的"吃饭"（灰）和能点的"火把"几乎一样亮，看不出哪个能按。建议灰的时候图标和字再暗一点，或者角标"0"变红。
- 顺序本身：从右往左 1、2、3，和阅读顺序相反，但按键的数字和位置对得上，用两次就习惯了。
