# BUG-010 等位置的恐龙在人群外面原地甩头（半圈栅栏、人站在门外时）

- 状态: open
- 严重度: 低～中（抽搐监测已经会报 `fidget` 了；只在一种摆法下、大约三次里两次）
- 发现: 2026-09-28 · 5ad2d35（TASK-013 复测 BUG-008 时，按任务说的"甩头本身另开 BUG"）
- 复现: `GODOT_PROJECT=$(bash debug-agent/tools/snapshot.sh 5ad2d35) bash debug-agent/tools/run_check.sh probe:half_fence`（人站在门外，不加 `DA_HERO_IN`），看 `twitch.txt` 里的 `fidget`

## 现象

背面加东头半圈栅栏，大波，人站在门外。一只腔骨龙站在船舱西南角外面 (−2.98, 3.61)，念头 ENGAGE → 船舱，一站就是十几秒，头每秒左右摆 25°～50°。三次里两次出现（我的计数器 16、14 次），监测报 `fidget`，每次 3 份：

```
#1 fidget (-3.0, 3.6) ENGAGE->core  6 s: path 0.45 net 0.27  挤着它的 4 只
#2 fidget (-3.0, 3.6) ENGAGE->core  6 s: path 0.00 net 0.00  3 只
#3 fidget (-2.9, 3.5) ENGAGE->core  6 s: path 0.13 net 0.13  1 只
```

报告里的状态：它的咬的位置（`slot`）是 (−2.0, 1.0)，在船舱西墙上；它自己站在离那个位置 **2.8 米**外，也就是 f65f8ea 说的"在人群外面等"的地方。状态 WALKING、动作 idle、朝向 −72°。

## 为什么（猜的，没改代码）

5ad2d35 的 `DINO_AI.face_target_within` 只管离自己的位置 **2 米以内**的："头只朝要咬的东西"。等位置的恐龙站在 2.8 米外，不在这个范围里，所以被旁边的同伴挤一下，头就跟着转，转回来，再被挤……。

## 期望

设计第 3 章："是同伴就排队等"；f65f8ea / 5ad2d35："等的站着不动、脸朝船舱"。在人群外面等的那一圈，也应该脸朝船舱（或朝自己的位置）站定。

## 对照

- 人先进船舱（`DA_HERO_IN=1`）的两次都没有出现（最多 4 次、0 次），只有 BUG-005 那边的 push。
- 一点不围的船舱（BUG-007 已修好）也没有出现。
